# 📚 React Book App
A React application for discovering and exploring books using the Gutendex API.

## ✨ Features
- Browse a collection of books
- Search for books
- View book details
- Fetch real-time data from Gutendex API

## 🛠️ Technologies
React • JavaScript • CSS • Vite • REST API
